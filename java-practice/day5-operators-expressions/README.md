# Day 5 — Java Marks Calculator

## Overview
A beginner Java project that calculates the total and average marks for three subjects. It includes a graphical user interface (GUI) built with Java Swing.

## Features
- Enter Programming, DSA, and DBMS marks.
- Calculate total marks and average marks.
- Display the average to two decimal places.
- Validate marks to ensure they are between 0 and 100.
- Handle invalid or non-numeric input.
- Use a desktop window with text fields, labels, and a Calculate button.

## Concepts Practised
- Java variables and data types (`int`, `double`, `String`)
- Arithmetic operators and expressions
- Integer and floating-point division
- Type casting
- `JFrame`, `JPanel`, `JTextField`, `JLabel`, and `JButton`
- Event handling with `addActionListener()`
- Exception handling using `try` and `catch`

## How to Run

Ensure that a compatible Java JDK is installed.

Compile the program:

```bash
javac MarksCalculator.java
```

Run the application:

```bash
java MarksCalculator
```

## Sample Calculation

- Programming: 80
- DSA: 75
- DBMS: 90
- Total: 245
- Average: 81.67
