# Day 3 — Java Student Profile

## Overview

A beginner Java program that demonstrates variable declaration, data types, and output using `System.out.println()`.

## Concepts Practised

* `String` — storing text
* `int` — storing whole numbers
* `double` — storing decimal numbers
* `char` — storing a single character
* `boolean` — storing true or false values
* String concatenation using `+`

## How to Run

Compile the program:

```bash
javac Student.java
```

Run the program:

```bash
java Student
```

## What I Learned

I learned how to declare variables of different data types, assign values to them, and display those values using Java output statements.
