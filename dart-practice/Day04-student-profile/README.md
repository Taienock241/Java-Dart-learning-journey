# Day 4 — Dart Student Profile

## Overview

A beginner Dart program demonstrating variable declarations, data types, string interpolation, and console output.

## Concepts Practised

* `String` — text values
* `int` — whole numbers
* `double` — decimal numbers
* `bool` — Boolean values
* Variable reassignment
* String interpolation using `$variable` and `${expression}`
* The `main()` entry point and `print()`

## How to Run

```bash
dart run main.dart
```

## What I Learned

I learned how to declare variables in Dart, store values of different types, interpolate variables into strings, and display a student profile in the console.

Dart
